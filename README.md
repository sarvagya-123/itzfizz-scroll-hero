# ITZFIZZ — Scroll-Driven Hero Section Animation

A high-performance automotive hero section built with **Next.js 14, Tailwind CSS, Framer Motion, and GSAP ScrollTrigger**.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Intro Animations**: Framer Motion
- **Scroll Physics**: GSAP + ScrollTrigger
- **Icons & Typography**: Lucide React + Next/Font (Inter, JetBrains Mono)

## Features
- **GPU Acceleration**: Utilizes hardware-accelerated transforms (`will-change: transform`) to maintain stable 60 FPS performance.
- **Physics-based Scrubbing**: Seamlessly maps physical scroll distance to object translation and scale.
- **Glassmorphic UI Elements**: High-contrast dark mode metric cards with micro-hover states.
